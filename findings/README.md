# 분석 결과 안내

현재 재현 파이프라인이 생성하는 주 분석은 다음 여섯 보고서다.

- `winning_capped_payouts.md`: 동결 상세 성적표와 격자 방향 감사
- `trifecta_feasible_sets.md`: 삼쌍승 상한 셀의 회계적 부분식별
- `masked_reconstruction.md`: 가상 상한 배분모형의 시간외 검증
- `sparse_multinomial_baseline.md`: 실제 상한 셀의 최소 대칭 기준선
- `dirichlet_multinomial.md`: 가상 상한 선택표본의 과산포 진단
- `cross_market_reconstruction.md`: 하위 승식 가격의 조건부 내부 정합성

나머지 문서는 탐색 과정의 과거 메모다. `censored_grid.md`, `point_id_gap.md`,
`tfoot_diagnosis.md`, `cells_committed.md`, `sales_verification.md`는 현재 파이프라인보다
앞선 진단 기록이며 수치나 주장이 충돌하면 위 여섯 보고서와 `README.md`를 따른다.
`gpt_test_response.md`는 분석 결과가 아니라 워크플로 연결 시험 기록이다.
