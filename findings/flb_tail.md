# 삼쌍승 `9999.9` 극단꼬리 FLB 진단

## 질문

삼쌍승 표시상한 `9999.9`에 속하는 조합 전체를 하나의 극단 longshot 집합으로 볼 때, 그 집합에 배분된 사전 마권질량이 실제 해당 집합에서 1·2·3착 결과가 나온 빈도보다 큰가를 검사한다.

이 검정에는 상한 셀 사이의 개별 마권배분이 필요하지 않다. 각 경주에서 `Y=1`은 실제 삼쌍승 적중조합이 `9999.9` 집합에 속함을 뜻하고, `Q`는 회계적으로 허용되는 상한 셀 전체의 마권질량을 전체 삼쌍승 마권수로 나눈 값이다. 따라서 `Y-Q<0`, 또는 집계한 `O/E<1`은 극단 longshot 집합이 실현빈도에 비해 과대베팅된 FLB 방향과 일치한다.

## 추론 방법

같은 경주일의 여러 경주가 독립이라고 가정하지 않는다. 경주일을 cluster로 삼아 날짜를 복원추출하는 bootstrap을 20,000회 수행하고 `O/E`와 평균 `Y-Q`의 95% 구간을 계산한다. 보조적으로 intercept-only 날짜-cluster sandwich 표준오차의 단측 정규근사 p값도 보고한다.

2022--2025 pooled midpoint에서 실제 적중은 회계적 마권질량이 시사하는 기대의 약 72.4%이며, 즉 극단 longshot 집합은 베팅질량 대비 약 27.6% 덜 적중했다. 날짜-cluster 95% 구간도 1 아래다. `residual_max`에서도 같은 결론이 더 강하게 유지된다. 반면 가장 보수적인 `residual_min`에서는 95% 구간 상단이 1.025로 1을 조금 포함한다.

2025년만 떼면 실제 capped 적중이 8회뿐이라 세 시나리오 모두 양측 95% bootstrap 구간이 1을 포함한다. 따라서 독립 확인표본 하나만으로 극단꼬리 과대베팅을 확정하는 결과는 아니다.

## 해석 경계

이 결과는 개별 `9999.9` 셀을 복원하지 않고도 식별되는 **극단꼬리 집합 수준** 결과다. 따라서 개별 상한 셀 배분모형이 만들어 낸 FLB가 아니다. 동시에 이것만으로 배당 전 구간에서 favorite에서 longshot으로 갈수록 수익률이 단조롭게 악화되는 고전적 형태의 FLB까지 입증한 것은 아니다.

다음 단계에서는 가상 상한 실험을 이용해 (1) 상한 집합 내부의 상대적 마권순위를 복원할 수 있는지, (2) 복원된 꼬리를 세분했을 때 원래 미검열 자료의 FLB 곡선이 보존되는지를 시간외 표본에서 검증한다. 이 검증을 통과한 경우에만 실제 `9999.9` 내부의 세부 FLB 기울기를 해석한다.
