# Dirichlet--multinomial 과산포 기준모형

## 추정과 시간외 검증

실제 `9999.9`가 없는 경주에 3,000·5,000·7,000 가상 상한을 적용한 정확 마권수 벡터로 대칭 Dirichlet--multinomial의 셀별 농도 `alpha`를 2022--2024년에 추정하고 2025년에 평가했다. `alpha→∞`는 대칭 다항모형이다.

| 가상 상한 | alpha | 훈련 경주 | 시험 경주 | 훈련 셀당 로그우도 개선 | 시험 셀당 개선 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 3000.0 | 19.250 | 1,399 | 535 | 15.39703 | 18.93450 |
| 5000.0 | 58.979 | 1,094 | 444 | 2.85516 | 3.44506 |
| 7000.0 | 268.293 | 676 | 296 | 0.24508 | 0.31839 |

## 실제 상한 셀에 외삽

실제 상한에 가장 가까운 7,000배 추정치 `alpha=268.293`를 사용했다. 경주별 잔여총량 `R`의 회계적 식별구간은 그대로 전파했다.

| 항목 | 값 |
| --- | ---: |
| 경주 | 7,546 |
| 실제 `9999.9` 셀 | 1,467,819 |
| 과산포모형 기대 무투표 (`R` 중간값) | 1.094e-09 (7.450e-14%) |
| `R` 식별구간 전파 범위 | 0--3,932 |

## 해석

2025년 로그우도 개선이 양수이면 가상 상한의 양의 작은 마권수에도 다항분포보다 과산포가 존재한다. 그러나 이 적합표본에는 실제 0이 없으므로, 실제 상한으로의 외삽은 구조적 0을 검정하거나 식별하지 않는다. 이 결과와 대칭 다항 결과의 차이는 분포가정 민감도이며 회계적 부분식별 구간을 대체하지 않는다. 기대값 범위의 상단은 785개 경주에서 회계적 `R` 하한이 0인 극단 시나리오를 합산한 값이다.
