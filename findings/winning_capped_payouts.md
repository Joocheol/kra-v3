# `9999.9` 당첨 배당의 실제 지급액 복원 — 전 승식

## 결론

배당판에서 `9999.9`로 표시된 셀 가운데 실제 당첨되어 KRA 상세 성적표에
정확한 지급배당이 발표된 사례는 **144건**이다.

| 승식 | 실제 지급액 복원 | 실제 지급액 > 9999.9 | 100원 마권 수 점식별 |
| --- | ---: | ---: | ---: |
| 단승식 | 0 | 0 | 0 |
| 연승식 | 0 | 0 | 해당 없음 |
| 복승식 | 0 | 0 | 0 |
| 쌍승식 | 0 | 0 | 0 |
| 복연승식 | 0 | 0 | 해당 없음 |
| **삼복승식** | **2** | **2** | **2** |
| **삼쌍승식** | **142** | **142** | **142** |
| **합계** | **144** | **144** | **144** |

즉 이 표본에서 실제 상한 초과 지급은 삼복승식과 삼쌍승식에만 있다. 복원된
144건은 모두 `9999.9`를 실제로 넘었고, 풀 매출액과 발표 배당을 결합했을 때
그 조합에 팔린 100원 마권 수도 모두 유일하게 정해졌다.

결과 데이터는 `데이터/winning_capped_payouts.csv.gz`에 있다.

## 1. 자료와 연결 방법

배당판 원본은 Dropbox의 다음 아카이브다.

```
/kra-analysis/data/raw_collected_v3_15w/
```

저장소의 `데이터/races.jsonl.gz`와 `데이터/cells/`는 이 원본을 파싱한 것이다.
19,301경주(2016--2019년, 2022--2025년)의 착순·승식별 매출액과 모든 배당판
셀을 담는다.

정확한 당첨배당은 배당판 원본에 없다. 배당판은 당첨 조합도 `9999.9`로
남겨 둔다. 대신 KRA의 **경주별 상세 성적표**는 실제 지급배당을 상한 없이
발표한다. 예를 들어 2017-06-11 부산경남 제5경주의 상세 성적표에는
삼복승식 `17274.2`, 삼쌍승식 `391736.8`이 찍혀 있다.

- [KRA 경주별 상세 성적표 예시](https://race.kra.co.kr/raceScore/ScoretableDetailList.do?Act=04&Sub=1&meet=3&realRcDate=20170611&realRcNo=5)
- [KRA 부산경남 승식별 최고평균배당](https://race.kra.co.kr/raceScore/RecordBaedang.do?Act=04&Sub=8&meet=3)

연결 절차는 다음과 같다.

1. 배당판에서 `cell_raw == "9999.9"`인 셀을 찾는다.
2. 착순을 이용해 실제 지급 가능 조합만 남긴다.
3. 후보 경주의 상세 성적표를 한 번만 받아 일곱 승식의 실제 지급조합·배당을
   모두 읽는다.
4. 승식과 조합이 배당판 후보와 정확히 일치하는 항목만 결과에 넣는다.

삼쌍승식의 저장소 page key는 `3Both`다. `3Bc`는 삼복승식이다.

## 2. 전체 `9999.9` 셀 중 당첨된 것은 얼마나 되는가

| 승식 | 배당판 `9999.9` 셀 | 실제 당첨·지급된 상한 초과 사례 |
| --- | ---: | ---: |
| 단승식 | 0 | 0 |
| 연승식 | 1 | 0 |
| 복승식 | 21 | 0 |
| 쌍승식 | 2,594 | 0 |
| 복연승식 | 2 | 0 |
| 삼복승식 | 136,260 | **2** |
| 삼쌍승식 | 3,774,486 | **142** |

연승식의 유일한 `9999.9` 셀은 `2016-07-01_2_08`의 3번마다. 3번마는
8두 경주의 3착이라 연승식 적중 가능 순위에는 들지만, KRA 상세 성적표의
지급배당 표에는 1착 8번과 2착 4번만 있고 3번마의 지급배당은 없다. 즉
3번마에 적중 마권이 팔려 실제 배당을 지급한 사례가 아니므로 복원 대상에서
제외했다.

쌍승식은 검열 셀이 2,594개나 있지만 실제 당첨 조합과 겹친 사례는 0개다.
검열 셀 수와 실제 상한 초과 지급 횟수는 전혀 다른 통계라는 점이 중요하다.

## 5. 마권 수 복원

단일 당첨조합 풀에서 실제 지급배당을 `D`, 풀 매출액을 `S`, 그 조합에 팔린
100원 마권 수를 정수 `n`이라 하면

```
D = (1-t) S / (100 n)
```

이다. 실제 발표값도 소수 첫째 자리로 반올림되므로, 등식 하나를 그대로
나누는 대신 그 반올림 구간에 들어가는 모든 정수 `n`을 정확한 유리수
연산으로 찾았다. 복원된 144건은 모두 후보 정수가 하나뿐이었다.

대표 사례:

```
2017-06-11_3_05 삼쌍승식
S = 375,638,000원, (1-t) = 0.73, D = 391,736.8
n = 7

0.73 × 375,638,000 / (100 × 7)
= 391,736.7714...  ->  소수 첫째 자리 391,736.8
```

연승식과 복연승식처럼 한 풀에서 여러 당첨조합에 각각 지급하는 승식, 또는
공동착으로 한 승식에 여러 배당이 생긴 경우에는 이 단일 당첨조합 공식을 쓰지
않도록 수집 코드에서 명시적으로 제외했다. 이번 실제 복원 144건은 모두
단일 당첨조합인 삼복승·삼쌍승이라 이 예외에 걸리지 않는다.

## 6. 연구에 주는 의미와 한계

이 144건은 인위적으로 가린 자료가 아니라 **실제로 배당판에서 검열됐지만
KRA가 정확한 지급액을 별도로 발표한 관측치**다. 따라서 복원 모형의 실제
외부 검증 표본으로 사용할 수 있다.

다만 이 표본은 무작위 검열 셀이 아니다. 실제 착순이 된 조합만 상세 지급액이
드러나므로 전체 3,774,486개 검열 삼쌍승 셀을 대표하지 않는다. 최종 검증은
다음 두 층을 함께 사용해야 한다.

1. 미검열 고배당을 인위적으로 `9999.9`로 가린 내부 검증
2. 이 파일의 실제 상한 초과 지급 144건을 이용한 외부 검증

다음 단계는 이 정답표본에 대해 `9999.9` 고정 기준선, 단승식 Harville,
삼복승식×쌍승식 결합, 회계·정수격자 제약 모형의 복원 오차를 비교하는 것이다.
