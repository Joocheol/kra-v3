# 가상상한 5승식 FLB 군집추론 보존검증

## 목적

실제 `9999.9` 복원 뒤 얻은 5승식 FLB가 복원절차 자체가 만들어낸 인공적 유의성인지 확인한다.

2022--2024 비상한 경주에서만 empirical rank profile을 학습하고, 완전관측 2025 경주에 7,000배·9,000배 가상상한을 씌웠다. 숨긴 실제 총마권수는 사용하지 않고 가시 배당과 매출에서 얻은 residual interval의 하한·중간·상한을 사용했다.

각 복원본을 삼쌍승→단승·복승·쌍승·삼복승으로 주변화하고, 각 승식의 longshot 10%·20%·40%에 대해 O/E를 계산했다. 경주일 cluster bootstrap 95% 구간(5,000회)으로 `FLB`(상한<1), `ANTI`(하한>1), `UNCERTAIN`을 분류했다.

비교 복원은 `Rmin_uniform`, `Rmid_uniform`, `Rmax_uniform`, `Rmid_rank` 네 가지다.

## 표본

- 7,000배 가상상한: 296경주
- 9,000배 가상상한: 105경주
- 평가 지표: 2 threshold × 5승식 × 3 tail = 30개

## 핵심 결과

| 복원 | 분류 일치 | 가짜 유의성 | 원래 유의성 누락 | 반대 판정 | 점추정 방향 일치 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Rmin uniform | 29/30 | 1 | 0 | 0 | 30/30 |
| Rmid uniform | 29/30 | 1 | 0 | 0 | 30/30 |
| Rmax uniform | 29/30 | 1 | 0 | 0 | 30/30 |
| **Rmid empirical rank** | **30/30** | **0** | **0** | **0** | **30/30** |

empirical rank-profile 복원은 완전자료의 군집추론 판정을 30/30 모두 보존했다. FLB가 없던 곳에 새 FLB를 만들지 않았고, 원래 FLB였던 곳을 놓치거나 반대로 뒤집은 곳도 없었다.

균등복원의 유일한 불일치는 9,000배 가상상한의 **복승 longshot 40%**였다. 완전자료는 O/E=0.510, 95% CI [0.127, 1.008]로 `UNCERTAIN`인데, uniform 복원은 세 residual 시나리오에서 상한이 0.970--0.998로 아주 조금 1 아래가 되어 `FLB`로 분류됐다. empirical rank 복원은 0.511 [0.125, 1.008]로 원래 `UNCERTAIN` 판정을 정확히 유지했다.

## 완전자료에서 원래 강건 FLB였던 예

7,000배 표본:
- 단승 tail 10%: truth O/E 0.218 [0.000, 0.676]
- 복승 tail 20%: 0.382 [0.000, 0.850]

9,000배 표본:
- 단승 tail 10%: 0.000 [0.000, 0.000]
- 복승 tail 10%·20%: 0.000 [0.000, 0.000]
- 쌍승 tail 10%·20%: 0.000 [0.000, 0.000]

이 판정들은 네 복원 시나리오에서 모두 유지됐다.

## 판정

1. **empirical rank-profile 복원은 이번 가상상한 실험에서 FLB 유의성을 기계적으로 생성하지 않았다.**
2. 점추정 방향은 네 복원 모두 30/30 보존되므로, 앞서 실제 capped 자료에서 관찰한 승식×longshot-depth 패턴은 개별 셀 복원오차에 상당히 강건하다.
3. 다만 uniform은 경계적인 CI에서 1건의 false positive가 있으므로, 세부 FLB 군집추론의 주 복원은 empirical rank-profile을 우선하고 uniform은 sensitivity 기준선으로 두는 것이 안전하다.
4. 이 검증은 threshold 7,000·9,000의 2025 완전관측 표본에 대한 결과다. threshold 선택 자체의 사후성을 줄이기 위해 후속 분석에서는 연속 percentile curve 또는 사전 고정 grid를 사용한다.
