# 절단 배당(9999.9)의 유한 격자 — K, N 실측

`데이터/races.jsonl.gz` (매출액) 와 `데이터/cells/page_key={Both,Bc,Scm}`
(셀 단위 배당률) 만으로 계산했다. 원본 아카이브도 Dropbox 경로도 쓰지 않았다.

## 쓴 공식 (지시서 그대로)

```
(1-t) = 73/100        # 쌍승식·복연승식 공제율 0.27
K = (1-t)·S / 100     # fractions.Fraction 으로 정확히, 부동소수점 없음
c = 9999.9 = 99999/10
N = ceil(K/c) - 1     # 후보 n ∈ {1, ..., N}
```

절단 셀의 정의: `section == "body"`, `col_header != "출전 번호"`,
`cell_raw == "9999.9"` (문자열 완전 일치). `spanned == 1` 인 그림자 셀은
제외했는데, 실제로 절단 셀 중 spanned 인 것은 **0개**여서 어느 쪽이든 결과는
같다.

계산 예 (검산용):

```
2016-06-17_2_05  복연승식  S = 1,771,900원
  K = 73/100 × 1,771,900 / 100 = 1293487/100 = 12,934.87
  K/c = 1.29349993...  ->  ceil = 2  ->  N = 1      (점식별)

2023-12-17_1_08  쌍승식    S = 528,811,400원
  K = 73/100 × 528,811,400 / 100 = 193016161/50 = 3,860,323.22
  K/c = 386.03618...   ->  ceil = 387 ->  N = 386
```

두 셀이 전부다:

| race_id | 조합 (행-열) | 복연승식 S | K | N |
| --- | --- | --- | --- | --- |
| 2016-06-11_2_02 | 1 - 9 | 2,575,500원 | 18,801.15 | **1** |
| 2016-06-17_2_05 | 3 - 9 | 1,771,900원 | 12,934.87 | **1** |

### N 의 분포

최소 = 1사분위 = 중앙값 = 3사분위 = 최대 = **1**.
N=1 이 2건(100%), 따라서 N≤5, N≤10, N≤50 도 모두 2건(100%).

### K 의 분포 (원)

최소 12,934 / 중앙값 15,867 / 최대 18,801.

**요약: 복연승식의 절단은 전 기간 두 셀뿐이고, 둘 다 N=1 로 점식별된다**
(O* = K). 둘 다 2016년 제주 경주로, 복연승식 매출액이 각각 258만원·177만원에
불과해 K 자체가 9999.9 를 겨우 넘긴 경우다. 쌍승식처럼 "인기 조합이 아니라
매출이 커서 절단"이 아니라, 반대로 **풀이 너무 작아서** 상한 K 가 절단선
바로 위에 놓인 경우다.

## 참고: Scm 페이지(단승·연승·복승)의 9999.9

예상은 "조합 수가 출주두수만큼(≤16)뿐이라 절단이 사실상 없다" 였다. 실측:

| 열 그룹 | 9999.9 셀 수 |
| --- | --- |
| 단승식 | **0** |
| 연승식 | **1** |
| 복승식 | **21** |

19,301 경주 × 세 풀에서 통틀어 22개. 예상대로 0에 가깝다. (복승식은 조합이
C(n,2) 라 단승·연승보다 많고, 그래서 21개가 거기 몰린 것으로 보인다.
지시대로 이들에 대해서는 K, N 을 계산하지 않았다.)
