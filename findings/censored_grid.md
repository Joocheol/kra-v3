# 절단 배당(9999.9)의 유한 격자 — K, N 실측 (네 풀)

`데이터/races.jsonl.gz` (매출액) 와 `데이터/cells/page_key={Both,Bc,3Bc,3Both,Scm}`
(셀 단위 배당률) 만으로 계산했다. 원본 아카이브도 Dropbox 경로도 쓰지 않았다.
3Bc·3Both 는 모든 `page_variant` 의 셀을 그대로 합쳤다 (중복 제거 없음).

## 쓴 공식

```
(1-t) = 73/100                  # 복승·쌍승·복연승·삼복승·삼쌍승 공제율 0.27
O = (1-t)·S / (100·m·n)         # n = 그 조합에 걸린 100원 마권 수, 정수 >= 1
K = (1-t)·S / (100·m)           # n=1 일 때의 상한
c = 9999.9 = 99999/10
N = ceil(K/c) - 1               # 후보 n ∈ {1, ..., N}
```

`fractions.Fraction` 으로 정확히 계산했다 (부동소수점 없음). m 판정에서는
표시값 재현 여부를 정수 구간 판정으로 풀었다 — `round(A/(B·n)) = D` 는
`n ∈ ( 2A/(B(2D+1)), 2A/(B(2D-1)) ]` 와 동치이므로, 정수 나눗셈만으로
후보 n 의 존재를 정확히 판정할 수 있다 (A = 73·S, B = 1000·m, D = 표시값×10).

절단 셀의 정의: `section == "body"`, `col_header != "출전 번호"`,
`cell_raw == "9999.9"` 완전 일치. 네 풀 통틀어 `spanned == 1` 인 절단 셀은
0개였다.

## 1. m 확정 — 네 풀 전부 아카이브 전량으로

미절단 수치 셀(`cell_raw` 가 `9999.9` 도 `1.0` 도 아닌 `\d+\.\d`, 대각선
마번 칸 제외) 각각에 대해, 후보 m 마다 "그 표시값을 만들어 내는 정수 n 이
존재하는가" 를 판정했다. 표본이 아니라 **전량**이다.

| page_key | 미절단 셀 | m=1 | m=2 | m=3 | m=4 | m=6 |
| --- | --- | --- | --- | --- | --- | --- |
| Both (쌍승식) | 1,936,702 | **99.985%** | 80.645% | 71.823% | 66.333% | 59.451% |
| Bc (복연승식) | 969,576 | **99.996%** | 98.718% | **99.994%** | 96.687% | 96.427% |
| 3Bc (삼복승식) | 8,429,007 | **99.984%** | 81.069% | 72.527% | 67.182% | 60.495% |
| 3Both (삼쌍승식) | 13,356,048 | **99.973%** | 58.776% | 43.715% | 35.695% | 27.005% |

### 이 표를 읽는 법 — 재현율은 한쪽으로 기울어 있다

m 이 크면 만들 수 있는 값의 집합이 **좁아진다**: `{A/(m·n) : n≥1}` 은
`{A/k : k≥1}` 의 부분집합(k = m·n)이다. 그래서 m=1 은 구조적으로 절대 지지
않는다. 이 검정에서 정보가 되는 것은 "m=1 이 이겼다" 가 아니라 **"큰 m 이
관측값을 만들어 내지 못해 기각된다"** 는 쪽이다.

- **삼쌍승식(3Both)**: m=2 는 표시값의 41%를, m=3 은 56%를 아예 만들어 내지
  못한다. 1,335만 셀 규모에서 이 정도 실패면 m≥2 는 기각된다. **m=1 채택.**
- **삼복승식(3Bc)**: m=2 가 19% 실패. 같은 이유로 **m=1 채택.**
- **쌍승식(Both)**: m=2 가 19% 실패. m=1 (기존 가정과 일치).
- **복연승식(Bc)**: m=1 (99.996%) 과 m=3 (99.994%) 이 사실상 동률이다.
  **이 풀만 재현율로는 갈리지 않는다** — 아래에서 따로 다룬다.

즉 이번 작업의 핵심인 삼복승식·삼쌍승식은 **m=1** 로 깨끗하게 확정된다
(차점 후보 m=2 와의 격차가 19%p·41%p).

m=1 로는 못 맞추는 잔여 0.015~0.027% 는 어느 풀에서나 비슷한 크기이고,
표시 반올림 규칙의 경계(내림/반올림 차이)나 발매 마감 후 정정 같은 것으로
보인다. 어느 m 을 골라도 남는 잔차라서 판정에는 영향이 없다.

### 복연승식의 m — 재현율로는 안 갈리고, 절단 셀에서 모순이 난다

지시서는 "복연승식은 m=3 으로 이미 확정" 이라고 한다. 시키신 대로 m=3 으로도
계산했는데, 결과가 자기모순이다.

| | m=1 | m=3 |
| --- | --- | --- |
| 절단 셀 2개의 K | 12,934원 / 18,801원 | 4,311원 / 6,267원 |
| K > c = 9999.9 인가 | 예 | **아니오** |
| N = ceil(K/c) − 1 | **1, 1** | **0, 0** |

m=3 이면 K < 9999.9 이므로 그 셀은 애초에 9999.9 로 절단될 수 없다. 그런데
데이터에는 9999.9 로 찍혀 있다. N=0 은 "후보 n 이 하나도 없다" 는 뜻이라
해가 없다. 아카이브 전량에서 미절단 표시값이 m=3 의 상한 K 를 넘는 셀도
1건 있다 (2016-08-26_2_07, 표시값 8113.0, K₍m=3₎ = 8,112.98 — 반올림 경계).

**이 파일에서는 복연승식도 m=1 로 계산한 값을 본 표에 싣고, m=3 값을 함께
적어 둔다.** m=3 이 다른 근거(과거 `p0_k_probe.py`)에서 나온 것이라면, 그
근거와 위 두 셀 중 어느 쪽이 맞는지는 이 데이터만으로는 정할 수 없다.
판단은 연구자 몫으로 남긴다. 어느 쪽이든 절단 셀이 2개뿐이라 다른 풀의
결론에는 영향이 없다.

### 계산 예 (검산용)

```
2024-06-01_1_01  삼쌍승식  S = 271,917,700원,  m = 1
  K = 73/100 × 271,917,700 / 100 = 198499921/100 = 1,984,999.21
  K/c = 198.50191...  ->  ceil = 199  ->  N = 198

2016-06-17_2_05  복연승식  S = 1,771,900원
  m=1: K = 12,934.87,  K/c = 1.29350  ->  N = 1     (점식별)
  m=3: K =  4,311.62,  K/c = 0.43117  ->  N = 0     (해 없음)
```

## 3. 삼쌍승식 상세 — 연구의 주 관심사

절단 셀 3,774,486개, 절단을 가진 경주 15,963개 (82.70%). 연도별:

| 연도 | 절단 셀 | 절단 경주 / 그 해 전체 |
| --- | --- | --- |
| 2016 | 399,659 | 1,348 / 1,539 (87.6%) |
| 2017 | 667,922 | 2,404 / 2,715 (88.5%) |
| 2018 | 545,632 | 2,267 / 2,703 (83.9%) |
| 2019 | 693,454 | 2,398 / 2,673 (89.7%) |
| 2022 | 527,726 | 1,974 / 2,356 (83.8%) |
| 2023 | 339,855 | 1,925 / 2,435 (79.1%) |
| 2024 | 299,001 | 1,803 / 2,454 (73.5%) |
| 2025 | 301,237 | 1,844 / 2,426 (76.0%) |

전 기간에 걸쳐 고르게 나타난다. 배당 셀의 22%가 절단이고, 경주의 83%가
절단 셀을 하나 이상 갖는다 — 삼쌍승식에서 절단은 예외가 아니라 상태의
기본값이다.

**N=1(점식별)은 3,774,486개 중 0개다.** 가장 좁은 격자가 N=2 이고, N≤10 도
1,984개(0.053%)뿐이다. 격자가 유한하다는 것만으로 삼쌍승식 절단 셀이 점으로
좁혀지는 일은 사실상 없다 — 절단 셀의 절반이 후보를 245개 이상 갖는다.

## 결론

삼쌍승식의 절단 셀은 3,774,486개(배당 셀의 22%, 경주의 83%)로 압도적으로
많지만 그중 N=1 로 점식별되는 셀은 **0개**이고 N 의 중앙값이 245라서, 유한
격자만으로는 부분식별 구간이 실질적으로 좁아지지 않는다 — 이 풀에서 쓸모를
만들려면 격자 밖의 정보(다른 풀의 배당 등)로 후보를 더 잘라야 한다는 것이
이 실측이 주는 첫 숫자다.
