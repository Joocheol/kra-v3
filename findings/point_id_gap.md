# 쌍승식 점식별 구간은 데이터에 존재하지 않는다

`findings/censored_grid.md` 에서 쌍승식 절단 셀 2,594개의 N 최솟값이 12 였고
N=1(점식별)이 한 건도 없었다. 이게 **우연히 못 걸린 것**인지 **그 구간 자체가
없는 것**인지를 가른다.

쓴 데이터: `데이터/races.jsonl.gz` 와 `데이터/cells/page_key=Both/*.csv.gz`
뿐이다. 원본 아카이브는 열지 않았다.

## 결론 한 줄

**우연이 아니다. 구간 자체가 존재하지 않는다.** 점식별에 필요한 쌍승식 발매금액
구간은 S ≤ 2,739,698원인데, 19,301경주 전체의 **최소 S 가 4,466,300원**이다.
구간 천장보다 1.63배 높다. 조건을 만족하는 경주는 **0건**이고, 따라서 3번
확인(그 경주들의 절단 셀 존재 여부)은 검사할 대상 자체가 없다.

---

## 1. 점식별 구간의 정확한 경계

N = 1 이려면 `ceil(K/c) = 2`, 즉 `c < K ≤ 2c` 여야 한다.
`K = (1-t)·S/100 = 73S/10000`, `c = 99999/10` 이므로 (`fractions.Fraction` 으로
정확히 계산):

```
S > 100·c/(73/100) = 99999000/73  = 1,369,849.3151...
S ≤ 200·c/(73/100) = 199998000/73 = 2,739,698.6301...
```

정수 원 단위로 **S ∈ [1,369,850원, 2,739,698원]**.
(참고: S ≤ 1,369,849원이면 K ≤ c 라서 N=0 — 절단 표시 자체가 나올 수 없다.)

## 3. 그 경주들의 절단 셀 확인

**검사 대상 0건 — 확인할 것이 없다.** 구간에 드는 경주가 하나도 없으므로
`page_key=Both` 에서 찾을 셀도 없다.

없는 N (= `ceil(K/c)-1`, 셀과 무관하게 S 만으로 결정된다) 을 19,301경주 전부에

## 정리

점식별 문턱(S ≤ 2,739,698원)은 이 데이터의 매출 분포와 **겹치지 않는다**.
가장 작은 경주조차 그 천장의 1.63배, 바닥의 3.26배다. 쌍승식에서 절단 셀의
점식별은 표본이 부족해서 안 되는 게 아니라 **구조적으로 불가능**하다 — 최선의
경우가 N=3 이고, 그 한 경주마저 절단 셀이 없다. 부분식별의 폭을 줄이려면 이
격자 하나만으로는 안 되고 다른 정보(교차 풀 등)를 붙여야 한다.
