# 교차시장 분석 입력 격자 검증

## 목적

교차시장 분석은 기존 `check_coherence.load_month` 로더를 사용한다. 이 로더는 딕셔너리로 셀을 적재하므로, 병합(spanned) 숫자 셀이나 서로 다른 값의 중복 키가 있으면 조용히 덮어쓸 위험이 있다. 2022--2025년 실질 분석 표본에 대해 원시 셀을 다시 읽어 이런 경로가 실제로 존재하는지 전수 검사한다.

## 결과

| 항목 | 결과 |
| --- | ---: |
| 검증 경주 | 9,671 |
| 읽은 숫자 셀 행 | 19,827,297 |
| 동일값 중복 행 | 2,823,966 |
| 서로 다른 값의 충돌 중복 | 0 |
| 숫자 spanned 셀 | 0 |
| 단승·복승·쌍승·삼복승·삼쌍승 활성마 조합 support | 전 경주 완전 일치 |

동일값 중복은 같은 조합이 여러 위치에 반복 표기된 경우이며 딕셔너리 덮어쓰기가 값을 바꾸지 않는다. 서로 다른 값의 충돌 중복은 0건이고 숫자 spanned 셀도 0건이다. 또한 다섯 대상 시장의 매핑된 조합 집합이 각 경주의 취소마를 제외한 활성마에서 계산한 이론 support와 전부 일치했다.

이 검사는 행·열 의미 자체의 외부 진실을 증명하지 않는다. 그 방향성은 상세 지급표, 페이지 표제, 2·3착 축 반전 반증모형으로 별도 검증한다. 여기서 확인한 것은 현재 2022--2025 표본에서 약한 로더가 spanned/충돌중복/누락 때문에 조용히 가격표를 바꾸는 경로가 없다는 점이다.
