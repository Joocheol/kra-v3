# 다중 승식 결합 삼쌍승 꼬리 복원

## 설계

실제 `9999.9` 복원에 다른 승식이 추가 정보를 주는지를 보기 위해, 실제 상한이 없는 2022--2025 삼쌍승 경주에서 3,000·5,000·7,000배 이상의 셀을 인위적으로 감췄다. 2022--2024의 마권배분만으로 계수를 학습하고 2025를 시간외 검증표본으로 사용했다. 실제 착순은 계수 학습에 사용하지 않았다.

입력 신호는 (1) 삼쌍승 내부 위치별 주변분포, (2) 삼쌍승 내부 1·2착 prefix, (3) 단승 Harville, (4) 쌍승 후 3착, (5) 삼복승 후 순서배분이다. 로그점수의 비음수 결합계수를 학습했고, 모든 비교모형은 외부 승식 자료가 완비된 같은 경주표본에서 평가했다.

## 학습된 신호

7,000배에서 다른 승식 결합의 계수는 단승 Harville 0.000, 쌍승 후 3착 0.045, 삼복승 후 순서 0.039였다(출력 반올림). 전체 결합에서도 삼쌍승 내부 위치모형 0.000, prefix 0.003으로 거의 사라지고 쌍승·삼복승 신호가 남았다. 다만 `exacta_then_third`와 `trio_then_order`의 구성 자체에 단승 확률이 조건부 순서배분 요소로 들어가므로, 단승 정보가 완전히 사용되지 않는다는 뜻은 아니다.

## 해석

다른 승식은 삼쌍승의 잘린 꼬리 안에서 상대적 인기도를 복원하는 데 실제 추가 정보를 제공한다. 그러나 그 정보량은 상한이 극단으로 갈수록 빠르게 감소한다. 실제 `9999.9` 영역은 7,000배 가상상한보다도 더 희소하므로, 현재 결과만으로 실제 각 상한 셀의 배당을 정확한 점값으로 복원한다고 주장해서는 안 된다.

따라서 FLB 분석에서는 먼저 상한 셀 전체의 회계적 총질량만 이용하는 allocation-free 검정을 주결과로 두고, 다른 승식 결합복원은 실제 상한 당첨셀 외부검증을 통과할 경우에만 `9999.9` 내부의 세부 FLB 기울기를 보는 보조분석으로 사용한다.
