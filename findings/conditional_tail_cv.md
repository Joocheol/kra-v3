# 조건부 꼬리보정 사전검증

## 설계

2025년 자료를 모형선정에서 완전히 제외하고, 2022--2024년 무상한 경주만으로 leave-one-year-out 교차검증을 실시했다. 후보는 shifted power-law 적합값 `(alpha, shift)`만 쓰는 경우와 여기에 셀당 유동성·출전두수를 추가하는 경우이며, 이웃 수 `k=25, 50, 100, 200`을 비교했다. 각 가상상한 3,000/5,000/7,000/9,000을 동일 가중하고, `후보 MAE / shifted-power MAE`의 네 임계값 평균을 선정점수로 사용했다. 1보다 작아야 단순 shifted power law보다 개선이다.

## 2022--2024 교차검증

| 조건 변수 | k | 선정점수 |
| --- | ---: | ---: |
| alpha, shift, 유동성, 출전두수 | 200 | **1.02637** |
| alpha, shift, 유동성, 출전두수 | 100 | 1.02643 |
| alpha, shift | 100 | 1.02727 |
| alpha, shift, 유동성, 출전두수 | 50 | 1.02730 |
| alpha, shift | 200 | 1.02733 |
| alpha, shift | 50 | 1.02763 |
| alpha, shift, 유동성, 출전두수 | 25 | 1.02967 |
| alpha, shift | 25 | 1.03124 |

최선 후보조차 1.02637로, shifted power law보다 약 2.6% 나쁘다. 따라서 **조건부 꼬리보정은 사전 기준에서 채택하지 않는다.**

## 손대지 않은 2025 진단

아래는 모형을 구제하기 위한 선정 결과가 아니라, 사전 기각 뒤의 진단이다. 공통지지 안 실제 상한 경주의 추가 near-tail masking MAE는 다음과 같다.

| 가상상한 | 조건부 보정 | shifted power law | 경험적 rank-profile | 균등배분 |
| ---: | ---: | ---: | ---: | ---: |
| 3,000 | 127.674 | **127.539** | 131.774 | 179.499 |
| 5,000 | **72.464** | 72.527 | 74.853 | 92.935 |
| 7,000 | 46.608 | 46.926 | **43.564** | 54.913 |
| 9,000 | 17.548 | 17.548 | **16.890** | 17.566 |

2025에서도 조건부 보정의 일관된 우위는 없다. 특히 실제 표시상한에 가까운 7,000--9,000 구간에서는 경험적 rank-profile이 더 낮은 MAE를 보인다.

## 판정

1. 경주별 `alpha`, shift, 유동성, 출전두수로 꼬리 보정량을 달리하는 현재 kNN 조건부 접근은 **기각**한다.
2. shifted power law는 간단하고 전체 rank-size 구조를 잘 설명하는 **구조적 기준선**으로 유지한다.
3. 경험적 rank-profile은 깊은 꼬리에서 더 좋은 성능을 보이는 **별도 경험적 benchmark**로 유지한다.
4. 2025 결과를 보고 조건부 규칙을 다시 조정하지 않는다. 그렇게 하면 holdout의 의미가 사라진다.
5. 이 검증은 실제 `9999.9` 셀 자체의 정답을 대규모로 관측한 검증이 아니라, 실제 상한 경주 안에서 추가로 숨긴 점식별 near-tail 셀에 대한 검증이다.
