# 실제 capped 경주 내부 pseudo-censoring: KRA3 동일-regime 복원 검증

## 핵심 판정

**다른 승식 정보, 특히 쌍승·삼복승은 실제 `9999.9`가 존재하는 경주 regime 안에서도 고배당 삼쌍승 셀의 상대적 마권분포를 유의미하게 예측한다.**

다만 이 결과는 `9999.9` 셀의 정확한 점배당을 식별한다는 뜻이 아니다. 검증이 직접 지지하는 것은 **상한 집합 내부의 상대순위/상대질량 배분**이다.

따라서 앞으로의 역할분담은 다음과 같이 두는 것이 가장 안전하다.

- **회계/매출 제약 + censored tail model:** capped 집합 전체에 얼마의 질량과 어떤 크기분포가 가능한가
- **쌍승·삼복승 정보:** 그 질량을 어떤 삼쌍승 조합에 상대적으로 더 많이 배분할 것인가
- **단승 Harville:** 현재 자료에서는 추가 신호가 거의 없음

## 설계

실제 `9999.9` 삼쌍승 셀이 존재하는 2022–2025 경주만 사용했다.

진짜 `9999.9` 셀은 마권 수를 모르므로 **입력에서도 평가에서도 완전히 제외**했다.

각 virtual threshold `u=3000,5000,7000`에서

\[
u\le D<9999.9
\]

이고 표시배당의 회계구간으로 마권 수가 한 값으로 점식별되는 셀만 인위적으로 가렸다.

- 2022–2024 capped 경주: 계수 학습
- 2025 capped 경주: 시간외 검증
- 착순 결과는 어떤 학습에도 사용하지 않음
- 숨긴 셀의 총 마권 수는 그 셀들의 알려진 진실로 조건화하고, 모형은 **그 총량을 셀 사이에 어떻게 배분할지**만 예측

비교모형:

1. uniform
2. same-pool joint: 삼쌍승 하위 visible 셀에서 위치/접두부 신호
3. cross-pool joint: 단승 Harville + 쌍승 + 삼복승
4. all joint: 위 모든 신호

## 해석

### 1. cross-pool 신호는 실제 capped regime에서도 존재한다

이전 비-상한 경주 가상상한 실험에서는 threshold가 극단으로 갈수록 cross-pool 신호가 빠르게 약해졌다. 그러나 실제 capped 경주만 사용한 동일-regime 검증에서는 7천배에서도 Spearman 약 0.33이 남고 MAE도 개선된다.

이는 **비-상한 경주가 실제 capped 경주의 좋은 학습표본이 아니었다**는 4단계 결과와 일관된다.

### 2. 쌍승과 삼복승이 핵심이다

모든 threshold에서 all-joint의 same-pool 계수는 0으로 수렴했고, 단승 Harville도 0 또는 0.001 수준이다.

실질적 예측력은

- 쌍승의 1·2착 순서 정보
- 삼복승의 세 마리 집합 정보

가 담당한다.

따라서 `9999.9` 내부 순위 복원에서 다른 승식을 쓴다면, 단승을 강제로 넣는 것보다 **쌍승+삼복승의 상대신호**를 중심으로 두는 것이 자료에 맞다.

### 3. 정확일치율이 낮은 것은 이상하지 않다

고배당 셀 수가 매우 많고 마권 수가 작은 정수이므로, 셀별 정확한 마권 수를 완전히 맞히는 문제는 매우 어렵다. 주목할 지표는 정확일치보다

- MAE
- log-count 오차
- rank Spearman
- 예측 상위 1/3에 실제 마권질량이 얼마나 집중되는가

이다.

3천배에서 cross-pool이 예측한 상위 1/3 조합에는 실제 masked 마권질량의 중앙 **43.9%**가 들어갔고, 균등이라면 약 33.3%다. 5천·7천배에서도 각각 약 **37.9%, 35.1%**로 신호가 남는다.

## 현재 복원 설계에 미치는 영향

이 결과는 cross-pool 정보를 **점복원기**가 아니라 **assignment/ranking model**로 채택할 근거를 준다.

실제 `9999.9` 복원에서 가장 자연스러운 구조는

\[
\text{회계적 총량/정수제약}
+
\text{전체경주 censored tail 분포}
+
\text{쌍승·삼복승 상대순위 신호}
\]

이다.

첫 두 요소는 `9999.9` 집합 안에 존재할 plausible 마권 수들의 multiset/분포를 제한하고, 세 번째 요소는 그 크기들을 어느 조합에 연결할지 정한다.

다만 실제 capped winner 8건 외부검증에서 단순 cross-pool 점배분이 균등보다 명확히 우월하지 않았던 결과는 그대로 유지한다. 따라서 **tail-size 분포와 cross-pool rank를 결합한 새 복원법을 만든 뒤 다시 실제 capped winner로 외부검증**해야 한다.
